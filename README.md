# Klicked releases

Downloads for Klicked, the Mac app that puts useful actions at your pointer.

Get the latest version from the [Releases page](https://github.com/KodieKonnect/klicked-releases/releases/latest).
Open the DMG and drag Klicked to Applications. Requires macOS 15 or later on Apple silicon.

`appcast.xml` in this repository is the update feed installed copies of Klicked check.
